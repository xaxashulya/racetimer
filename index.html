Добавить участника

Можно заранее забить только фамилии — номер участник получит на месте, и его можно будет присвоить позже кнопкой «Выдать номер».

Импорт / экспорт CSV

Заголовки столбцов: bib,name,category,gender,agegroup (или на русском: номер,имя,категория,пол,группа). Разделитель — запятая. Столбец с номером не обязателен — можно импортировать только фамилии, а номера присвоить позже.

Чтобы вести хронометраж на другом устройстве: экспортируйте список здесь, передайте файл (флешкой, в мессенджере, по почте) и импортируйте его там.

Список участников

🔎

«Оч. старта» — если заранее известен порядок старта, задайте номер очереди (1, 2, 3…) у нужных участников — они станут раньше остальных, по возрастанию. У кого 0 (по умолчанию) — стартуют в обычном порядке по номеру. Если у нескольких участников одинаковая очередь старта — при выборе следующего на старт отметятся сразу все они.

Настройки старта

Отметьте галочками одного, нескольких или сразу всех участников в очереди — они стартуют вместе. В автоматическом режиме по истечении интервала выбранные участники стартуют сами. В ручном режиме отсчёт не идёт — старт фиксируется только по нажатию кнопки «Старт».
